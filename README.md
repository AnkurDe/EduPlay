# EduPlay

EduPlay is a browser-based educational gaming platform developed as a second-semester web development project. The platform combines learning and entertainment through interactive games designed to improve knowledge, memory, and decision-making skills.

## Features

- Interactive educational games
- Responsive and user-friendly interface
- Multiple game modules accessible from a single homepage
- Lightweight browser-based implementation
- Gamified learning experience

## Games Included

### 1. Symbol Up
An educational quiz based on the Periodic Table.

**Features**
- Interactive periodic table
- Random element selection
- Quiz mode
- Improves familiarity with chemical elements

---

### 2. Red Light Green Light
A traffic awareness game where players drive while obeying traffic signals.

**Features**
- Traffic signal simulation
- Timer and scoring system
- Leaderboard
- Promotes understanding of road safety rules

---

### 3. Memory.co
An image-assisted crossword puzzle game.

**Available Levels**
- Indian Food
- Animals

**Features**
- Crossword puzzles
- Picture-based clues
- Answer validation
- Multiple difficulty levels

## Installation

1. Clone the repository.
    ```bash
    git clone https://github.com/AnkurDe/EduPlay.git
    ```

2. Open the project folder.
3. Launch `Main.html` in any modern web browser.

No additional software or dependencies are required.
